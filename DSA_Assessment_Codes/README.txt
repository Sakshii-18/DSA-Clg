DSA Assessment Codes
====================

This folder contains separate Python files for the code examples pasted in chat:

01. Singly Linear Linked List
02. Doubly Linear Linked List
03. Singly Circular Linked List
04. Doubly Circular Linked List
05. Stack using Linked List
06. Linear Queue using Linked List
07. Circular Queue using Linked List
08. Deque using Linked List
09. Priority Queue using Linked List

Note: These files preserve the logic of the pasted examples as closely as possible.
Some original examples have edge-case limitations (for example, operations on an empty list).
They are study/reference files, not fully hardened implementations.
